# k6 v2.0.0 for z/OS (s390x)

This is the z/OS port of k6 v2.0.0 for the s390x architecture.

## What's New in v2.0.0

k6 v2.0.0 is a major release that includes breaking changes and removes deprecated functionality. See the [upstream v2.0.0 release notes](v2.0.0.md) for full details.

## z/OS Specific Notes

- Built with Go 1.25.7 on z/OS
- Includes LIBPATH fix for iewbndd6.so dependency
- Tested on z/OS 3.1

## Download

Download the binary from the [Releases page](https://github.com/msradam/k6/releases/tag/v2.0.0-s390x).

## Installation

```bash
tar -xzf k6-v2.0.0-zos-s390x.tar.gz
chmod +x k6
./k6 version
```
